# Compatibility verification

The native implementation was checked against the upstream MkPFS source rather than only against its own verifier.

| Check | Result |
|---|---|
| Native PFSC output decoded by upstream `decode_pfsc_payload` | Passed for a 589,824-byte raw PFS fixture; decoded bytes were identical |
| Native four-inode wrapper checked by upstream `mkpfs verify` | Passed with zero warnings and zero errors |
| Wrapper inode summary | Four inodes, one directory, one file, one compressed file |
| Wrapper logical payload | 524,288 bytes |
| Wrapper CRC32 | `0xEB87F8DD` |
| Wrapper manifest SHA-256 | `54e2a33b28b5f97cc9eb11a6c98301a58700eb49f42f6d6281b4514547a35207` |
| Native regression suite | Passed |
| Linux payload build | Passed |

The fixture used for the wrapper check was generated by the upstream exFAT writer, then wrapped by the native implementation. This confirms the native PFSC encoder and outer PFS serialization, but it does not yet prove that a native folder scanner and exFAT serializer are complete; that part remains guarded by `ENOTSUP` in `mkpfs_convert_folder`.
